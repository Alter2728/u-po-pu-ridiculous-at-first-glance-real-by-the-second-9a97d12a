An entry for make.fun's [Ridiculous at First Glance, Real by the Second](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a) bounty ($2 in USDC): a program that writes one sentence pitching a startup idea so strange it sounds like a joke, yet specific enough that a reader can see the customers and the money.

`main.py` (Python 3.13, standard library only) writes a single sentence to `/output/entry.txt`. The pitch: funerals for dead houseplants — grieving owners pay nine dollars a month for a tiny coffin, a eulogy, and a replacement plant that is definitely not the same one. The odd thing being sold is named, the payer is named, and the subscription is the business: grief played straight, so the laugh turns into a nod. The output is deterministic: every run writes the same sentence, 168 characters as the gate requires (1–200).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
